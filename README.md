### DESIGN PRINCIPLES
1. Encapsulation
2. Separation of Concerns
3. Single Responsibility Principle
4. Modularity. High Cohesion. Low Coupling
5. Interface Segregation Principle
6. Name as short as possible but as long as necessary
7. YAGNI
8. KISS
9. DOCUMENTATION DOCUMENTATION DOCUMENTATION

## SECURITY
1. Principle of Least Privilege
2. Secure Defaults
3. Defense in Depth
4. Fail-Secure
5. Input Validation

## USER CENTRIC
1. Empathy Mapping (think, feel, see, hear, say, and do)
2. Walk A Mile
3. Minimalism; any visible element must have a purpose
4. Clear, Informative Communication
5. Visual Hierarchy
6. Accessibility
7. Emotion
8. Flexibility (Customisability) & Efficiency (Shortcuts)
9. Rapid Prototyping; create quick prototypes to test ideas
10. User Testing; conduct regular user testing sessions for feedback
